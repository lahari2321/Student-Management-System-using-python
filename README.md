# Student-Management-System-using-python
A console-based Student Management System in Python using OOP concepts. Supports adding, updating, removing, and viewing student details with class-wise grouping.

📘 Student Management System (Python OOP)
A console-based Student Management System built using Object-Oriented Programming (OOP) in Python.
This project allows users to manage student records such as adding, updating, deleting, and viewing details class-wise and school-wide.

✅ Features
1.Add new student details
2.Update student name, phone number, address, or class
3.Remove student record
4.View a single student by roll number
5.Display all students in the school
6.View students of a specific class
7.Update school name (class method)
8.Get total student count
🧠 Concepts Used
Classes & Objects
Class variables and methods
Dictionaries for data storage
List handling
Menu-driven program
